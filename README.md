# open-data-ai-analytics

## Мета проєкту

Створення модульного аналітичного проєкту для роботи з відкритими державними даними.
Проєкт включає завантаження, перевірку якості, дослідження та візуалізацію даних.

## Джерело відкритих даних

Дані: "101. Середньомісячна номінальна заробітна плата за регіонами 
(у розрахунку на одного штатного працівника; грн)"

Портал відкритих даних України:
https://data.gov.ua/

## Питання / гіпотези для аналізу

1. Як змінювалась середньомісячна заробітна плата в Україні з часом?
2. Які регіони мають найвищі та найнижчі показники заробітної плати?
3. Чи спостерігається сезонність або тренд зростання заробітної плати?
